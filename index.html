Algebra & Calculus Cheat Sheets

Number Rules

a · 0 = 0
1 · a = a
a · (1/a) = 1 (a ≠ 0)
a + (-a) = 0

Expand Rules

a(b + c) = ab + ac
-(a ± b) = -a ∓ b
(a + b)(c + d) = ac + ad + bc + bd
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²

Fractions Rules

a/b + c/d = (ad + bc) / bd
a/b - c/d = (ad - bc) / bd
(a/b) · (c/d) = ac / bd
(a/b) ÷ (c/d) = (a/b) · (d/c) = ad / bc

Exponent Rules

xᵃ · xᵇ = xᵃ⁺ᵇ
xᵃ / xᵇ = xᵃ⁻ᵇ
(xᵃ)ᵇ = xᵃ·ᵇ
x⁻ᵃ = 1 / xᵃ
x⁰ = 1 (x ≠ 0)
(xy)ᵃ = xᵃyᵃ

Radical Rules

√(ab) = √a · √b
√(a/b) = √a / √b
x^(a/b) = ᵇ√(xᵃ)

Logarithm Rules

log(ab) = log(a) + log(b)
log(a/b) = log(a) - log(b)
log(aᵇ) = b·log(a)
logₐ(a) = 1
logₐ(1) = 0

Derivatives

d/dx (c) = 0
d/dx (xⁿ) = n·xⁿ⁻¹
d/dx (sin x) = cos x
d/dx (cos x) = -sin x
d/dx (eˣ) = eˣ
d/dx (ln x) = 1/x

Integrals

∫ xⁿ dx = (xⁿ⁺¹) / (n+1) + C
∫ sin x dx = -cos x + C
∫ cos x dx = sin x + C
∫ eˣ dx = eˣ + C
∫ (1/x) dx = ln|x| + C

Trigonometric Identities

sin²(x) + cos²(x) = 1
tan(x) = sin(x) / cos(x)
cot(x) = cos(x) / sin(x)
sin(2x) = 2·sin(x)·cos(x)
cos(2x) = cos²(x) - sin²(x)
0

ax² + bx + c = 0

a₁x + b₁y = c₁
a₂x + b₂y = c₂
