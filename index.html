Number Rules

a · 0 = 0
1 · a = a
a · (1/a) = 1 (a ≠ 0)
a + (-a) = 0

Expand Rules

a(b + c) = ab + ac
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²

Exponents & Radicals

xᵃ · xᵇ = xᵃ⁺ᵇ
(xᵃ)ᵇ = xᵃ·ᵇ
x⁻ᵃ = 1 / xᵃ
√(ab) = √a · √b

Trigonometry

sin²(x) + cos²(x) = 1
tan(x) = sin(x)/cos(x)
sin(2x) = 2sin(x)cos(x)

Calculus Basics

d/dx(xⁿ) = n·xⁿ⁻¹
d/dx(sin x) = cos x
∫ xⁿ dx = xⁿ⁺¹/(n+1)
